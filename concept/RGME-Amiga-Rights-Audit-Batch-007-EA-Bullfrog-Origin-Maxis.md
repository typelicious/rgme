# RGME Amiga Library Rights Audit — Batch 007
## Electronic Arts / Bullfrog / Origin Systems / Maxis

**Date:** 2026-10-28  
**Status:** Evidence-backed family audit; title/release/component rights remain decisive.

## Executive summary

This batch demonstrates a different rights pattern from Psygnosis: Electronic Arts has unusually strong present-day continuity across several acquired or integrated studio families.

The local Amiga collection contains substantial material from:

- **Bullfrog** — Populous, Populous II, Powermonger, Syndicate and related material;
- **Origin Systems** — Ultima and Wing Commander-era titles;
- **Maxis** — SimCity, SimAnt and SimEarth-era simulation titles;
- the wider **Electronic Arts publishing catalogue**.

Current EA and authorized-store catalogues continue to sell numerous Bullfrog and Origin classics, while EA's own Maxis history states that Maxis became part of EA in 1997. This produces high-confidence current licensing routes for the major franchises.

It still does **not** justify:

```text
EA published game in 1989
        =
EA owns every right in that game in 2026
```

RGME must preserve developer, publisher, franchise, trademark, likeness and release-specific rights as separate graph edges.

## Bullfrog pattern

For core Bullfrog properties, the EA route is particularly strong.

EA currently maintains official classic-product material for *Populous* and *Syndicate*, identifying Electronic Arts as publisher and Bullfrog Productions as developer.

This makes titles such as:

```text
Populous
Populous II
Syndicate
Theme Park
```

excellent BYOG modernization targets but weak unlicensed public-distribution candidates.

### RGME technical relevance

Bullfrog games are particularly valuable because they test mouse-heavy strategy/simulation UX rather than only joystick action.

Potential modernization work:

- gamepad-controlled pointer;
- modern mouse scaling;
- zoom/presentation layers;
- semantic shortcuts;
- save-state UX;
- touch adaptation;
- optional accessibility overlays.

## Origin pattern

EA's current catalogue still includes *Ultima* and *Wing Commander* classics.

This provides a strong present-day rights/licensing route for the core franchises.

For RGME these games introduce new modernization concerns:

- keyboard-heavy controls;
- text input;
- flight controls;
- multi-disk handling;
- RPG save semantics;
- manuals/reference material;
- potentially complex copy-protection/document dependencies.

The original Amiga release remains a distinct rights-bearing release even when another platform's edition is currently sold.

## Maxis pattern

EA's official Maxis history states:

```text
1987  Maxis founded
1989  SimCity
1993  SimCity 2000
1997  Maxis becomes part of Electronic Arts
```

The current SimCity franchise remains actively exploited by EA/Maxis.

For RGME this family is valuable because simulation titles test:

- pointer precision;
- high-resolution display handling;
- UI scaling;
- keyboard shortcuts;
- long-running save state;
- modern-window presentation.

## External-license overlay

Some EA-published titles demonstrate why the Rights Graph needs more than software copyright.

Example:

```text
Ferrari Formula One
        |
        +--> game code
        +--> graphics
        +--> music
        +--> publisher rights
        +--> Ferrari name / trademark
        +--> potentially motorsport-related licenses
```

Likewise a sports title using named athletes may involve:

```text
software rights
+
name / likeness rights
+
league / event marks
```

A corporate-successor graph alone cannot resolve those.

## New Rights Intelligence concept — Rights Layers

Batch 007 suggests formalizing:

```ts
type RightsLayer =
  | "software"
  | "franchise"
  | "trademark"
  | "character"
  | "music"
  | "artwork"
  | "likeness"
  | "sports_license"
  | "vehicle_brand"
  | "documentation";
```

A policy decision must be able to say:

```yaml
action: public_remaster

software:
  status: permitted

trademark:
  status: unknown

likeness:
  status: restricted

decision: review
```

This is more accurate than assigning one legal status to the whole game.

## Corporate-level update

Electronic Arts announced completion of its acquisition by the PIF / Silver Lake / Affinity Partners consortium on 4 August 2026.

For RGME this should be modeled as:

```text
EA
  |
  | ownership/control event
  v
Consortium ownership
```

rather than rewriting every game's rightsholder to the names of EA's shareholders.

This distinction should become an explicit Rights Graph rule:

> **Corporate ownership of a rightsholder is not the same graph relation as assignment of an IP right.**

## Licensing opportunity

### Low-priority direct licensing

Major active franchises:

- SimCity;
- Ultima;
- Wing Commander;
- Syndicate;
- Populous.

They are valuable technical BYOG targets but likely inefficient first licensing targets.

### More interesting archaeology

Less actively exploited EA/Bullfrog/Origin catalogue items may justify deeper title-specific research, especially where:

- no current release exists;
- original creators are identifiable;
- trademark exposure is low;
- no third-party brand/likeness license is involved.

## Architectural consequence

The Rights Graph now needs at least these relationship types:

```text
DEVELOPED_BY
PUBLISHED_BY
ACQUIRED_COMPANY
OWNS_IP
OWNS_TRADEMARK
LICENSED_TO
LICENSED_FROM
DISTRIBUTED_BY
CURRENTLY_SOLD_BY
USES_LIKENESS
USES_BRAND
DERIVED_FROM
EXPANSION_OF
```

This is substantially richer than a `current_ip_holder` column and reinforces the case for the dedicated Rights Intelligence specification proposed in RGME Overall Concept v0.3.

## Batch conclusion

Batch 007 provides four reusable rights patterns:

1. **Acquired studio + actively exploited IP** — Bullfrog / EA.
2. **Acquired studio + actively sold legacy catalogue** — Origin / EA.
3. **Integrated studio + continuing franchise** — Maxis / EA.
4. **Publisher plus external licensed IP** — selected EA catalogue titles.

The fourth pattern is especially important: even perfect software-rights evidence may still be insufficient for a public remaster.
