# RGME Amiga Library Rights Audit — Batch 005
## Team17 / Classic Amiga Catalogue

**Date:** 2026-10-28  
**Status:** Evidence-backed family audit; title-specific ownership remains required.

## Executive summary

Team17 is unusually useful for RGME because the company itself provides strong historical continuity. Its official history describes the company's Amiga origins, identifies *Alien Breed*, *Superfrog*, *Project X* and *ATR: All Terrain Racing* among its classic catalogue, and describes *Worms* as its defining long-running franchise.

At the same time, Team17's corporate reporting explicitly distinguishes **first-party owned IP** from **third-party IP**. RGME therefore must not infer ownership merely from a Team17 publishing credit.

The strongest current finding is *Alien Breed*. In September 2026 Team17 announced **Alien Breed 35th Anniversary Collection**, explicitly describing a collection of the original-era games in their original formats, optimized with modern controls, new modes and archival/history material.

That is extremely close to one important RGME product pattern:

```text
Original Game
     +
Original Format Preservation
     +
Modern Controls
     +
Modern Compatibility
     +
Archive / Museum Context
```

It validates the category commercially while also making Alien Breed a clearly active IP that RGME must not publicly redistribute without permission.

## Core rights findings

### Worms

Worms remains one of Team17's defining active franchises. Team17's current catalogue contains numerous Worms products and its corporate history traces the franchise back to the 1995 Amiga release.

**RGME classification:** Class D / active commercial IP.

Recommended use:

- local BYOG runtime testing;
- no bundled binary;
- no public remaster without license;
- potentially valuable future corporate licensing discussion only after RGME has a strong demonstrator.

### Alien Breed

Alien Breed is even more strategically interesting because Team17 is actively revisiting the original catalogue in 2026.

The announced 35th Anniversary Collection includes original-format preservation, modern controls and historical/archive content.

**RGME classification:** Class D / active commercial IP.

This is simultaneously:

- a poor unlicensed public-demo candidate;
- an excellent competitive/market reference;
- an excellent private BYOG technical target.

### Project-X / Superfrog / Body Blows / Assassin / Overdrive / Full Contact

These are historically strong Team17 catalogue relationships, but RGME should still verify title-specific current ownership before claiming Team17 owns every component today.

The distinction matters because Team17 itself has historically operated both as:

- owner/developer of first-party IP;
- publisher of third-party IP.

### Demos and special editions

The local library contains several demo/special-edition records. These must remain separate release identities until hashes and metadata establish their exact relationship.

A magazine demo is not automatically redistributable merely because it was historically distributed on cover media.

## Market-pattern finding

The 2026 Alien Breed collection is a useful external validation of RGME's modernization thesis.

RGME's differentiation should therefore not be:

> “We can put an old game in an emulator.”

It should be:

> **A generalized infrastructure that can identify an exact historical release, resolve an appropriate execution strategy, modernize controls and presentation, preserve authenticity, attach rights evidence, and apply reproducible enhancements across many catalogues.**

## Licensing implication

Team17 is probably not an early rights-acquisition target. It is an active, sophisticated publisher with its own retro exploitation capability.

A better sequence is:

1. prove RGME using legally distributable/freeware material;
2. demonstrate BYOG modernization with Team17 titles privately;
3. establish differentiated capabilities such as multi-runtime execution, evidence-backed rights intelligence and enhancement packages;
4. only then consider a partnership/licensing pitch.
